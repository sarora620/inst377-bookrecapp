# inst377-bookrecapp

My UMD INST377 final project: A book recommendation app

I found that the best way to reduce my screentime was to read, but I find it difficult to find new books without spiralling into reviews and accidentally happen upon spoilers. This recommendation website allows users to select a broad genre and maximum amount of pages which we then query to open library and filter to produce a list of books that match the page count & genre and a list that matches just the genre.

The target browser for this website is Mac and Windows. This UI is not ideal for smartphones of any kind.

for developer docs, please navigate to: https://github.com/sarora620/inst377-bookrecapp/blob/main/docs/developer_manual.md
